Settings

Site Mode

Basic is just search and request: guests search Spotify and send a song, and you see the queue and play it. Full turns everything back on exactly as you left it - nothing is deleted when you switch.

Event Details

Event Name is the headline guests see (e.g. "Sarah's 30th Birthday"). Venue Name is usually where it's happening, shown underneath in smaller text - leave it blank to hide it.

Requests

Turn off to stop new guest requests.

Requests open
Guest Credits

How many requests each guest can bank, and how fast they refill.

Location

When on, guests must be within the check-in distance of the pinned venue location to request a song. Turn it off to let anyone request from anywhere.

Location lock
Check-In Distance

How close, in meters, a guest has to be to the pinned venue location for Location Lock to let them request.

Venue Code Display Time

How long the rotating code stays up on your Visuals screen when a guest asks for it (5 to 300 seconds).

Screensaver

After this long without touching this screen, the live queue (same as the venue screen) fills the display. Tap anywhere to close it. Set to 0 to turn it off (at least 5 seconds otherwise). Saved on this device only.

Kiosk Settings

Display-only mode turns the kiosk page into a full-screen, read-only "now playing" board with no search, credits or voting.

Kiosk requests open
Display-only mode
Danger Zone

Reset puts credits, queue cap, filters, location lock, kiosk and music video settings back to their defaults. It keeps the event name, venue, Spotify connection, queue, history, blocked guests and the schedule.

Permanently deletes this event and everything in it - queue, history, settings, Spotify connection. This can't be undone, and the URL becomes free for anyone to reuse.

Music

What Guests Can Request

Songs that break a rule are hidden from guest search and refused if someone tries to request them anyway. Switch a rule off to allow that kind of song.

Explicit allowed
Remixes allowed
Live versions allowed
Radio edits only

Remixes covers titles marked Remix, Sped Up, Slowed, Nightcore, Bootleg or Mashup. Live versions covers titles marked Live, Live at..., Live From... or Unplugged. Radio edits only hides extended, club, dub, instrumental and other long mixes, and keeps radio edits and normal versions. These work from the song's title, so a song with no label in its title can still slip through.

Decades (Theme Nights)

Pick any decades to limit guests to songs released in those decades. Leave none picked to allow every decade.

Queue Limit

When on, requests close automatically once the queue reaches the limit, and reopen as songs play.

Queue limit on
Repeat Gap

How many other songs have to play or leave the queue before the same song can be requested again. 0 turns the rule off.

Blocking whole genres, specific songs or artists is on the Blocked page.
